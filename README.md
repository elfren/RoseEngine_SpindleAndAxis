New functionality: 

Reciprocation added to MultiSync page:
Setting an axis Waves field to any positive number will divide that axis' distance into plus and negative direction legs. Setting the field to a negative number will cause that axis to reverse direction for each leg of the wave. At least one axis must have a positive value for reciprocation to be active. Only one positive setting will be used. Setting the field to 0 will cause that axis to only move in the selected direction for that axis.  

LoadIni page:
Settings can be saved to a file named Settings.ini.  The file will be overwritten if it exists on the microSD card.
